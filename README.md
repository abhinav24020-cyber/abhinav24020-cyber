### 🚀 Featured project: [Trend → Ad, an autonomous AI ad studio](https://github.com/abhinav24020-cyber/r2c-trend-to-ad-pipeline)

Crawls 10+ sources for what's trending in AI, ranks the trends, and turns each one into a branded, ready-to-post ad for Instagram, Facebook and LinkedIn, with no manual design.

<a href="https://github.com/abhinav24020-cyber/r2c-trend-to-ad-pipeline">
  <img src="https://raw.githubusercontent.com/abhinav24020-cyber/r2c-trend-to-ad-pipeline/main/docs/hero.png" alt="Ads generated by the pipeline" width="100%">
</a>

- **Trend intelligence:** Crawlee crawler → Gemini embeddings → clustering → cross-platform and ranking gates
- **Copywriting with guardrails:** an LLM writes the copy and code rejects hype, invented claims and clichés
- **Generative visuals:** a creative-director LLM pass, then FLUX.2 Klein 9B on Cloudflare Workers AI
- **Brand-safe output:** a code-driven template typesets the logo, text and CTA, so nothing is misspelled
- **130 unit tests** and built to run on free tiers
